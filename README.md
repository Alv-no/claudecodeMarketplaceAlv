# ALV Claude Code marketplace

Install the marketplace and then a plugin from inside Claude Code:

```
/plugin marketplace add https://github.com/Alv-no/claudecodeMarketplaceAlv.git
/plugin install myfirsttool@alvmarketplace
```

## Plugins

- **myfirsttool** — All-in-one plugin: file-protection hooks, auto-linting, audit logging, desktop notifications, and a `/deploy-check` skill. See [myfirsttool/README.md](myfirsttool/README.md).
